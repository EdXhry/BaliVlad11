# Статус проекта - Bali Real Estate Events Aggregator

## Что работает:

### 1. Парсинг источников
- PP Bali (ppbali.com) - работает, нашел 5 событий
- Venaso Bali (venasobali.com.au) - работает, нашел элементы
- Telegram каналы (@bali_invest, @terraauri) - требуют прокси/VPN

### 2. База данных
- PostgreSQL подключена
- Миграции применены (добавлена колонка source_name)
- События сохраняются корректно

### 3. Формирование дайджеста
- Формат по ТЗ:
  ```
  📅 Дата и время (WITA)
  📍 Место/район
  🏷 Формат: офлайн/онлайн | Тип: форум/конференция/встреча/выставка
  🧵 Тема: 1 короткое предложение по сути
  🗣 Спикеры: ФИО/компания (если указано)
  Язык: RU | EN | RU+EN
  🔗 Источник: кликабельная ссылка на оригинал
  ```
- Дедупликация работает
- Фильтрация по теме/гео/языку работает

### 4. Telegram бот
- Подключение работает через прокси
- Тестовые сообщения отправляются
- Публикация дайджеста требует исправления Markdown

### 5. Панель управления
- Веб-интерфейс на FastAPI
- Добавление источников
- Кнопка "Обновить сейчас"
- Управление расписанием

## Файлы проекта:

- `sources.json` - список источников (2 TG канала + 2 сайта)
- `source_configs.yaml` - конфигурация парсеров
- `processor.py` - обработка и фильтрация событий
- `digest.py` - формирование дайджеста по ТЗ
- `bot.py` - Telegram бот
- `panel.py` - веб-панель управления
- `demo_bot.py` - демонстрация работы с тестовыми данными
- `migrate_db.py` - миграция базы данных

## Как запустить:

1. Тест бота:
```bash
python main.py test-bot
```

2. Демонстрация с тестовыми данными:
```bash
python demo_bot.py
```

3. Панель управления:
```bash
python panel.py
```

4. Планировщик:
```bash
python main.py
```
